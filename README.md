# سیستەمی پیشەیی بەڕێوەبردنی ستۆرج باتری

سیستەمێکی هۆشمەند بۆ بیرخستنەوە و بەڕێوەبردنی کاتی چارجکردنی باتری هەموو ٤٠ ڕۆژ جارێک.

## تایبەتمەندییەکان

- 🔋 **بەڕێوەبردنی باتری**: تۆمارکردن و بەدواداچوونی باترییەکان
- 📊 **داشبۆردی پیشەیی**: پێشاندانی گشتی لە چاوپێکەوتنێکی جوان
- 📱 **ناوبری مۆبایل**: ناوبری خوارەوە بۆ مۆبایل
- 🗂️ **لایبری لاتەراڵ**: لایبری پیشەیی بۆ دێسکتۆپ
- ⏰ **ئاگادارکردنەوە**: یادەوەری دوای ٤٠ ڕۆژ
- 📈 **شیکاری**: ڕاپۆرتی پیشەیی و شیکاری ستاندارد
- 🔄 **پاشەکەوت**: دەرهێنان و هێنانی دراوەکان
- 🎨 **دیزاینی مۆدێرن**: UI/UX پیشەیی

## چۆنیەتی بەکارهێنان

1. **دامەزراندن**: `npm install`
2. **کارپێکردن**: `npm run dev`
3. **بنیاتنان**: `npm run build`

## تەکنەلۆژیاکان

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 4
- Lucide React Icons

## ناوبری

### دێسکتۆپ
- **لایبری لاتەراڵ**: ناوبری سەرەکی لە لای ڕاست
- **هێڵی ژووری خاکی**: کردارە خێراکان لە خوارەوە

### مۆبایل  
- **ناوبری خوارەوە**: ٥ بەش سەرەکی
- **مینووی مۆبایل**: لایبری کامل بۆ مۆبایل

## بەشەکان

1. **داشبۆرد** - پێشاندانی گشتی
2. **باترییەکان** - بەڕێوەبردنی باترییەکان  
3. **شیکاری** - ڕاپۆرت و ئامار
4. **ئاگادارکردنەوە** - یادەوەری و هۆشدارییەکان
5. **مێژوو** - تۆماری چالاکییەکان
6. **ڕێکخستن** - بژاردە و ڕێکخستنەکان
