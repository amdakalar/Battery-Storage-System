# سیستەمی پیشەیی بەڕێوەبردنی ستۆرج باتری (Battery Storage System)

سیستەمێکی پێشکەوتووی بەڕێوەبردن و بەدواداچوونی ستۆرجی پاتری بۆ بیرخستنەوە و بەڕێوەبردنی کاتی چارجکردنی باتری بە شێوەیەکی خۆکار.

## داگرتنی بەرنامە (Download Release)

بۆ داگرتنی نوێترین وەشانی فەرمی و فایلی Setup، تکایە سەردانی بەشی [Releases](https://github.com/amdakalar/Battery-Storage-System/releases/latest) بکەن.

---

## تایبەتمەندییەکان

- 🔋 **بەڕێوەبردنی باتری**: تۆمارکردن و بەدواداچوونی باترییەکان
- 📊 **داشبۆردی پیشەیی**: پێشاندانی گشتی لە چاوپێکەوتنێکی جوان
- ⏰ **ئاگادارکردنەوە**: یادەوەری بۆ کاتی چارجکردنی خەزن
- 📈 **شیکاری**: ڕاپۆرتی پیشەیی و شیکاری ستاندارد
- 🔄 **پاشەکەوت**: دەرهێنان و هێنانی دراوەکان (JSON Backup & SQLite DB)
- 🎨 **دیزاینی مۆدێرن**: UI/UX پیشەیی بۆ دێسکتۆپ

## چۆنیەتی کارپێکردن لە پەرەپێدان

1. **دامەزراندن**: `npm install`
2. **کارپێکردن**: `npm run dev`
3. **دروستکردنی Setup**: `npm run release`
